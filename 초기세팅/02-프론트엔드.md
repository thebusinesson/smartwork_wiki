# Frontend 초기세팅

## 설치와 개인 환경변수

새 터미널에서 smartwork 저장소 루트를 기준으로 실행한다.

```bash
cd frontend
yarn install --frozen-lockfile
```

권위 있는 lockfile은 `yarn.lock`이다. 기존 `pnpm-lock.yaml`이 있어도 설치 기준으로 사용하지 않는다. frozen 설치가 실패하면 Node·Yarn 버전, package.json과 lockfile의 불일치, registry·사내 CA를 확인한다. 최초 세팅을 위해 의도하지 않은 의존성 갱신을 커밋하지 않는다.

`frontend/.env`가 없을 때 `.env.example`을 개인 설정으로 복사한다. 기존 파일이 있다면 값을 확인하여 필요한 키만 보완한다.

```bash
if [ ! -e .env ]; then
  cp .env.example .env
fi
```

| 키 | 로컬 설정·의미 |
|---|---|
| VITE_API_URL | 기본 `/api/v1`. Vite의 `/api` 프록시를 통해 localhost:8080 API로 연결 |
| VITE_APP_TITLE | 화면의 앱 표기용 제목 |
| VITE_LOG_LEVEL | 개발 로그 수준; 실제 사용자·민감정보를 로그에 추가하지 않음 |
| VITE_AUTH_DISABLED | 실제 로그인·권한 검증에서는 미설정 또는 false. 백엔드 인증 우회와 함께 쓰는 개발 편의 모드와 구분 |
| VITE_SMARTBILL_BASE_URL | 연결할 스마트빌 레거시 환경. 개발·데모·운영 대상을 확인한 뒤 설정 |
| VITE_VISIT_POLICY_EFFECTIVE_DATE | 방문 통계 기준 변경의 해당 환경 실제 적용일. 담당자가 확정하지 않은 날짜를 임의로 채우지 않음 |

`VITE_` 값은 브라우저 코드에 포함될 수 있으므로 비밀번호·서버 비밀키를 넣지 않는다. 실제 값·키 이름의 원본은 [.env.example](https://github.com/thebusinesson/smartwork/blob/dc216b3130faabcfc1dce7dbc9bd2e3b8fbecefc/frontend/.env.example)이다. 과거 개인 `.env`에 `VITE_USE_MOCK_API`가 있어도 현재 구조의 기능 전환 옵션으로 취급하지 않는다.

## 실행과 API 연결

```bash
yarn dev
```

기본 주소는 <http://localhost:5173>이다. 시작 로그에 다른 포트가 표시되면 기존 프로세스 점유 여부를 확인한다. Backend는 별도 터미널에서 기동해야 한다.

```text
브라우저 localhost:5173
  → /api/v1/...
  → Vite /api proxy
  → backend localhost:8080
```

VITE_API_URL을 절대 URL로 바꾸면 Vite 프록시를 거치지 않으며 CORS·쿠키·인증 조건을 별도로 맞춰야 한다. 환경변수를 바꾼 뒤에는 Vite를 재시작한다. API 포트를 바꿀 때는 프록시 대상도 맞춘다. 디버그 중 다른 앱이 8080을 사용하고 있다면 어느 프로세스가 실제 응답하는지 확인한다.

## 개발 검사

frontend 디렉터리 기준이다.

```bash
yarn lint
yarn test --run
yarn build
```

애플리케이션 TypeScript만 확인하려면 다음을 사용한다.

```bash
npx tsc -p tsconfig.app.json --noEmit
```

루트 tsconfig.json은 solution 구성이므로 단순 `tsc --noEmit`만으로 앱 소스 전체를 검사했다고 판단하지 않는다. `yarn build` 스크립트는 `tsc -b && vite build`다.

## 코드 작업을 시작할 위치

화면·전용 API는 feature/도메인 아래에 두고 여러 업무가 공유하는 코드는 shared를 사용한다. 기존 Hook → API 흐름을 따른다. 스타일 작업 전 DESIGN.md, 검색·테이블·페이지네이션·오류 표시를 바꾸기 전 frontend/docs의 관련 가이드를 읽는다.
