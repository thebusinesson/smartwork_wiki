# SmartWork 관리자 매뉴얼

제공받은 **WBS 탭의 작업자 `유지윤`**을 기준으로 작성한 페이지별 관리자 매뉴얼이다.

**[전체 매뉴얼 목차 및 조사 상태](inventory/wbs-pages.md)**

- 대상: WBS 태스크 105개, 현재 메뉴 56개, 독립 화면 경로 134개.
- 문서 형식: 화면 기본 정보 → 권한·준비 → 사용 절차 → 입력·표시 데이터 → API·DB·연계 → 예외 대응 → 검증·출처.
- 현재 상태: 코드·개발 DB 정의 조사 완료, 업무·화면 검토 대기. 실제 실행 검증 범위는 아래 문서를 확인한다.
