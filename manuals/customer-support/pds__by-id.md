## 3) 화면 사용 절차

1. 관련 화면에서 대상 또는 작업을 선택하여 `/customer-support/pds/:id`로 이동한다. 경로 변수는 주소에서 임의로 바꾸지 않고 이전 화면이 전달한 식별자를 사용한다.
2. 대상의 기본 정보·상태·표시 항목을 확인한다. 목록의 식별자와 상세 대상이 일치하는지 확인한다.
3. **수정, 삭제** 중 필요한 작업을 선택한다. 버튼의 표시·활성 조건과 아래 API별 권한을 확인한다. 저장·삭제·외부 호출 전에는 대상과 현재 상태를 재확인한다.
4. 작업 결과 또는 다운로드 파일을 확인하고 관련 목록으로 돌아가 변경된 상태를 다시 조회한다.

**이 화면에서 유의할 업무 규칙**: 본문과 첨부파일을 구분한다. 저장 시 JSON payload와 선택적 file을 함께 전송하며 수정 시 기존 첨부 유지·삭제·교체의 실제 선택 상태를 확인한다. 원래 파일명과 저장 파일 경로를 구분한다.
