## 3) 화면 사용 절차

**검증 시 화면 버튼**: 목록. 화면 상태·대상에 따라 달라지며 아래 작업 절차와 권한 조건을 함께 확인한다.

1. 월별 목록에서 조회할 월의 일별 상세 링크를 선택한다. 주소의 `yearMonth=YYYY-MM`를 유지한다.
2. 상세에 표시된 조회월과 일별 집계 항목을 확인한다. 별도 날짜 입력으로 검색하는 화면은 아니다.
3. 월별 합계와 비교할 때 조회월·집계 대상을 일치시킨다.
4. 확인 후 **목록**으로 월별 화면에 돌아간다.

**이 화면에서 유의할 업무 규칙**: 월별 화면에서 이용월을 선택해 일별 상세로 이동한다. 월별 합계와 일별 합계의 집계 대상·기간을 맞춰 비교한다.

**조회월 전달**: 이 상세 화면은 별도 검색 입력 대신 `yearMonth` 쿼리로 조회월을 받는다. 월별 화면에서 선택한 `YYYY-MM` 값을 유지하여 이동한다. 쿼리가 없으면 코드의 현재 월 기본값을 사용하므로, 직접 경로를 열어 확인한 결과와 특정 월에서 이동한 결과를 비교할 때 조회월을 먼저 맞춘다. **목록**으로 복귀한다.
