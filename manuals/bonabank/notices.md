## 1) 화면 기본 정보

### 도메인 이해

보나뱅크 구분으로 관리되는 회사·회원과 전자세금계산서 업무를 운영하는 영역이다. 고객 정보, 문서 현황, 국세청 신고 실패, 이용 통계와 공지를 함께 확인하되 현재 메뉴의 보나뱅크 범위를 유지한다.

| 구분 | 설명 |
|---|---|
| 업무 영역 | 보나뱅크 서비스 운영 · SB 서비스관리 > 보나뱅크 > 공지사항 관리 |
| 주요 대상·용어 | 보나뱅크 회사·회원: 이 서비스 구분의 고객 정보 / 신고 실패: 국세청 관련 처리에서 실패로 분류된 내역 / 공지: 서비스 안내 게시물 |
| 업무 흐름 | 보나뱅크 고객 식별 → 회사·회원 또는 문서·통계 선택 → 상태·이력 확인 → 필요한 지원 작업 |
| 이 페이지의 역할 | 보나뱅크 공지 업무의 진입 화면이다. 보나뱅크 서비스 안내 게시물의 제목·내용과 게시 정보를 관리한다. 같은 메뉴의 팝업·탭은 이 문서에서, 독립 상세·등록·수정 화면은 관련 문서에서 다룬다. |
| 관련 업무와 구분 | 스마트빌 전체 고객 목록과 보나뱅크 목록은 범위가 다를 수 있다. 세금계산서 목록의 상세 이동은 공통 세금계산서 화면으로 연결되는 현재 구현을 따른다. |

도메인 설명 근거: 이 문서 7번의 현재 메뉴·라우트·화면 및 API·업무 규칙 소스. [전체 도메인 지도](../../references/domain-overview.md#bonabank). 설명 보강일 2026-11-09; 기존 실행 검증 범위와 미확인 상태는 변경하지 않았다.

## 3) 화면 사용 절차

**검증 시 화면 버튼**: 검색, 작성, 목록. 화면 상태·대상에 따라 달라지며 아래 작업 절차와 권한 조건을 함께 확인한다.

1. `SB 서비스관리 > 보나뱅크 > 공지사항 관리` 메뉴를 연다. 경로 변수는 주소에서 임의로 바꾸지 않고 이전 화면이 전달한 식별자를 사용한다.
2. 현재 검색 조건과 아래 기본값을 확인한다. **검색** 항목에 필요한 값을 입력하고 **검색**을 누른다.
3. 결과 행에서 업무 대상을 선택하여 관련 상세 화면으로 이동한다. 페이지 이동·검색 조건 변경 후에는 현재 조건과 조회 대상을 다시 확인한다.

**이 화면에서 유의할 업무 규칙**: 목록은 제목 검색이 기본이며 10건 단위다. 작성 버튼으로 신규 공지를 등록한다. 상세 조회는 조회수를 증가시키므로 목록과 상세의 조회수가 달라질 수 있다. 등록·수정은 실제 PROCESS 권한을 확인한다.
