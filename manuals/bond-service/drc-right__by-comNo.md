| 구분 | 설명 |
|---|---|
| 업무 영역 | 채권잔액 확인 서비스 > 담당자 권한 조회 상세 |

| 주요 대상·데이터 | 업체 번호와 그 업체에 연결된 담당자·권한 표시 정보가 대상이다. |
| 업무 흐름 | 업체 식별 유지 → 담당자·권한 정보 확인 → 문의 사용자와 대조 |

| 판단 결과·다음 업무 | 담당 권한 문제인지 업체·문서 자체 문제인지 구분해 관련 담당에게 전달한다. |
| 다른 화면과의 구분 | 연동 시스템의 접근 경로·URL 설정이나 전체 SmartWork 관리자 메뉴 권한과 같은 데이터가 아니다. |

## 3) 화면 사용 절차

**검증 시 화면 버튼**: 목록. 화면 상태·대상에 따라 달라지며 아래 작업 절차와 권한 조건을 함께 확인한다.

1. 관련 화면에서 대상 또는 작업을 선택하여 `/bond-service/drc-right/:comNo`로 이동한다. 경로 변수는 주소에서 임의로 바꾸지 않고 이전 화면이 전달한 식별자를 사용한다.
2. 대상의 기본 정보·상태·표시 항목을 확인한다. 목록의 식별자와 상세 대상이 일치하는지 확인한다.
3. **더보기, 접기** 중 필요한 작업을 선택한다. 버튼의 표시·활성 조건과 아래 API별 권한을 확인한다. 저장·삭제·외부 호출 전에는 대상과 현재 상태를 재확인한다.
4. 작업 결과 또는 다운로드 파일을 확인하고 관련 목록으로 돌아가 변경된 상태를 다시 조회한다.

**이 화면에서 유의할 업무 규칙**: 검색어로 업체를 찾은 뒤 상세에서 회사 및 담당자 권한을 확인한다. 조회 권한과 실제 권한 변경 작업의 존재 여부는 아래 화면 버튼·API 계약 기준으로 구분한다.
