## 3) 화면 사용 절차

1. 관련 화면에서 대상 또는 작업을 선택하여 `/payment/refund-management/new`로 이동한다. 경로 변수는 주소에서 임의로 바꾸지 않고 이전 화면이 전달한 식별자를 사용한다.
2. **사업자번호, 환불은행, 환불계좌, 환불신청금액**의 입력값을 확인한다. 신규 값을 입력한다. 필수값과 형식 오류가 표시되면 해당 항목을 수정한다.
3. **저장**을 누르고 확인창이 있으면 대상·작업을 확인한다. 첨부가 있으면 기존 파일의 유지·삭제·교체 선택을 함께 확인한다.
4. 처리 결과 메시지를 확인한 뒤 목록 또는 상세에서 결과를 다시 조회한다. 오류가 나면 아래 예외 대응과 API 오류를 확인하고 중복 저장 전에 기존 처리 여부를 확인한다.

**이 화면에서 유의할 업무 규칙**: 목록의 기본 기간은 7일 전~오늘이다. 환불 가능 금액 조회와 신규 등록은 별도 화면이다. 환불 가능 금액은 잔액·사용량·기환불·수수료 등의 규칙이 적용되므로 표시 금액과 상세 이력을 확인한다. 기존 신청의 정보 수정과 상태 변경은 상세 화면에서 수행한다.

공통 폼이 등록·수정·상세 입력값 조회 함수를 함께 포함할 수 있다. 아래 API 표에 공통 구현의 다른 모드가 표시되어도 현재 경로의 작업으로 모두 실행하는 것은 아니다.
