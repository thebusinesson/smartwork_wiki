# 페이지 누락·도메인 설명 일관성 검증

확인일 **2026-11-10**. 코드 기준 `dc216b3130faabcfc1dce7dbc9bd2e3b8fbecefc`, 검토 시작 Wiki 커밋 `e8f8e2b`.

## 결론

**선정 WBS 범위의 독립 경로 누락은 없다.** 원문 유지윤 담당 105개 태스크·56개 메뉴 범위에 대응하는 실제 등록 경로 134개와 페이지 문서 134개가 일치한다. 누락 문서 0개, 등록되지 않은 경로를 문서화한 사례 0개, 현재 라우트 컴포넌트와 문서의 화면 출처 불일치 0개다.

**도메인 설명이 완전했다고 보지는 않는다.** 실제 변경 작업이 조회 설명에 충분히 드러나지 않은 사례 등 17개 문서를 보완했고, WBS 명칭 차이 1개 문서의 제한을 다시 명시했다. 총 18개 문서에 9개 유형의 점검 결과를 반영했다. 오류 접수의 UI/API 전달 차이와 보나뱅크 WBS 명칭 대응은 후속 확인 항목으로 남긴다.

이 결론의 범위는 사용자가 지정한 유지윤 담당 WBS 업무다. SmartWork 전체 메뉴 또는 배포 환경의 모든 화면에 매뉴얼이 있다는 결론이 아니다. 브라우저 진입 미재현 12개 경로와 저장·외부 발송·금액 처리·역할별 거부 검증의 기존 한계도 그대로다.

## 독립적으로 대조한 근거

1. 사용자 제공 붙여넣기 원문에서 유지윤이 있는 105개 행을 세고, 선정 CSV의 태스크명·원문 행을 모두 대조했다. 원본 Excel을 다시 열어 시트·병합 셀을 독립 확인한 것은 아니다.
2. TypeScript AST로 `routes/index.tsx`의 prefix·section을 읽고 실제 domain 라우트의 path·component·props를 추출했다. 기존 문서 목록을 정답으로 간주하지 않고 추출한 경로와 양방향 집합 비교했다. 경계는 메뉴 경로 전체와 그 하위 `/` 경로로 잡아 이름이 비슷한 다른 메뉴를 섞지 않았다.
3. `menuConfig.ts`의 label 있는 메뉴만 추출했다. 제목 보정용 경로·주석을 사이드바 메뉴로 세지 않았다. 대상 하위 메뉴 진입점은 57개로, 기존 56개 업무 범위에 `오류 접수/등록`의 `/error-management/error-reports/new` 진입도 포함한다. 이 경로는 이미 134개 문서에 포함되어 있어 신규 문서 누락이 아니다.
4. 134개 경로의 실제 컴포넌트와 ‘도메인 이해’의 직접 출처를 대조했다. SPF 게시판 28개 경로는 C/D/E/F/G/N/H type prop과 설명의 유형이 일치하는지도 확인했다. 같은 폼·컴포넌트의 재사용과 등록·수정·게시판 분기를 함께 읽었다.
5. 조회 외 작업은 화면의 버튼·확인창·핸들러와 연결 API/서버 조건을 확인했다. 중요한 행위 누락·잘못된 경계·UI와 요청 계약의 차이를 아래처럼 보완했다. 문자열이 서로 다르다는 이유만으로 업무 설명이 맞다고 판정하지 않았다.

## 경계가 다른 화면·기존 한계

- 회사정보와 소속 회원·권한·변경 이력은 각각 회사 설정, 회원 역할/탈퇴, 서비스 권한, 과거 스냅샷으로 구분한다. 보나뱅크에서 공통 컴포넌트를 쓰는 경우 데이터·권한이 자동으로 모두 보나뱅크 전용으로 바뀐다고 가정하지 않는다.
- 홈택스 실행 모니터링·오류 로그·등록 현황·만료·로그인 실패·이메일 파싱은 실행 여부, 오류 내용, 등록/과금, 유효기간, 인증 실패, 별도 수집 경로로 나누어 설명했다. 자동/수동 실행은 같은 페이지의 다른 영역이지 빠진 독립 페이지가 아니다.
- 일반/현행/과거/보나뱅크 문서와 통계의 포함 범위·작성일·문서 구분을 유지한다. 독립 statement 경로의 상세 API 재사용·미구현 다운로드, 공통 상세 document 분기, 보나뱅크 목록의 공통 상세 이동을 같은 동작으로 합치지 않는다.
- 다른 담당 범위의 회원 상세·로그인·설정 또는 외부 관리 팝업으로 연결될 수 있다. 대상 업무의 연결 화면이라는 이유만으로 WBS 담당 범위를 확대하거나 그 페이지가 누락되었다고 판정하지 않았다.
- DB 메타데이터 정의와 코드 확인은 실제 배포 메뉴·역할 계정·쓰기 성공·최종 메일 수신·금액 반영을 증명하지 않는다. 이 검증에서는 새 로그인·프로시저 실행·변경·발송을 하지 않았다.
