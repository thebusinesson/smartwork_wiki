| 원문 조회 권한·API 누락 | 48 | 화면에서 연결한 원문 조회 API 51개와 서버의 UNMASK 권한, 요청·응답과 관련 근거를 추가했다. |
| 입력란 이름이 버튼으로 표시 | 33 | 입력 요소의 접근성 이름을 버튼·작업명 목록에서 뺐다. |
