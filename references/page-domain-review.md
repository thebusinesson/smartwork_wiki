# 페이지별 도메인 설명 대조

확인일 2026-11-10. 15개 영역의 공통 설명을 반복했던 이전 방식을 교체했다. 134개 페이지에서 실제 사용하는 상황·데이터·업무 흐름·판단 결과·다음 업무·다른 화면과의 차이를 각각 기록했다. 화면 기본 정보의 짧은 목적도 해당 경로에 맞췄다.

같은 컴포넌트·폼을 실제로 공유하는 화면은 공통 구조를 그대로 밝히되, 진입 경로·게시판 유형·대상·등록/수정 단계의 차이를 설명했다. 이름만 바꾸어 별개 기능이라고 설명하지 않는다. 2026-11-10 추가 감사에서 [페이지 누락·도메인 설명 일관성 검증](coverage-domain-audit.md)으로 실제 등록 경로와 변경 기능을 다시 대조하고 18개 문서를 보완했다. 아래 표는 재작성한 문서와 대조한 화면 소스의 대응표이며, 7개 항목 양식과 기존 API·DB·실행 검증 기록은 유지한다. DB·화면을 새로 실행하지 않았으며 기존 미확인 항목을 완료로 바꾸지 않았다.
